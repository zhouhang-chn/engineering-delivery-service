Initialize the `engineering-delivery-service` repository as a Python project skeleton per the architecture doc (section 17), using **uv**.

## Steps

1. **git init** the repo.
2. **Project config**: `pyproject.toml` (uv, Python ≥3.11) with core dependencies declared but installed later: `google-adk`, `fastapi`, `uvicorn`, `sqlalchemy`, `psycopg[binary]`, `alembic`, `pydantic`, `docker`, `a2a-sdk` (guarded — pin what's available on PyPI), plus dev deps `pytest`, `ruff`. Create `.python-version`, `.gitignore`, `README.md` (project overview, milestone summary, how to set up with uv).
3. **Directory structure** (doc §17), each module with a docstring explaining its responsibility and a minimal stub:

```
agent/supervisor.py            # ReAct Supervisor (Google ADK) — stub
agent/prompts/                 # supervisor prompt templates
a2a/server.py                  # A2A endpoint — stub
tools/work_order.py            # Delivery Control tools: Work Order CRUD
tools/project.py               # project / repository resolution
tools/runtime.py               # runtime lifecycle tools
tools/worker.py                # worker control tools
tools/inspector.py             # inspector control tools
tools/deployment.py            # deploy_candidate / get_deployment_status
control/state.py               # deterministic state primitives
control/repository.py          # git operations
control/policy.py              # retry / timeout / approval policies
codex/app_server_client.py     # Codex App Server client — stub
codex/worker_driver.py         # worker driver — stub
codex/inspector_driver.py      # inspector driver — stub
sandbox/manager.py             # sandbox lifecycle — stub
deployment/docker.py           # Docker deploy — stub
db/models.py                   # SQLAlchemy WorkOrder models (minimal draft)
db/migrations/                 # alembic setup placeholder
```

4. **Infra files**: `docker-compose.yml` (PostgreSQL service), `.env.example`.
5. **Verify**: `uv sync` runs cleanly (installing core deps) and `uv run pytest` / `uv run ruff check` pass on the empty skeleton; add a trivial smoke test so pytest has something to run.
6. **Initial git commit** with the scaffold.

No deterministic workflow layer is added (per doc §17) — control logic stays as primitives for the Supervisor.
